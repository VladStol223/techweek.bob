First: Open a Folder

Bob needs an open folder to do anything useful — write code, create files, remember context. Without one, it's just a chat window.

Open Folder in the Explorer panel
In the Explorer panel (left sidebar), click Open Folder. Navigate to your folder and click Select Folder. Bob is ready to go the moment the folder loads.
Use a dedicated, empty folder
Create a fresh, empty folder just for your Bob work — something like ~/bob-workspace. Bob can read every file in the open folder, so keeping it dedicated means it only ever sees what you intentionally put there. Don't open your home directory, Documents, or any folder with sensitive files.

What the Engineering Audit Skill Does (9 Stages)

A single /engineering-audit command kicks off a structured 9-stage workflow that Bob runs autonomously. No templates to fill in. No checklist to follow manually. Bob does the work and reports findings in a structured format you can act on immediately.

The 9 Audit Stages Bob Runs Autonomously
Stage 1 — Repository Discovery
  Maps every layer: frontend, backend, DB, auth, tests, CI/CD, secrets.
  Produces a full Architecture Map before touching source code.

Stage 2 — Technical Audit
  Opens source files. Classifies every finding: Critical, High, Medium, Low,
  False Positive, or Product Decision Required.
  Every finding includes: location, steps to reproduce, root cause, fix, effort.

Stage 3 — Product Decision Gate
  Any finding that requires a business decision is escalated here.
  Bob presents options, tradeoffs, and a recommendation. Waits for your input.

Stage 4 — Remediation
  Implements the smallest safe fix for every Critical and High finding.
  Adds regression tests where feasible. Marks each finding [FIXED].

Stage 5 — Independent Verification
  Acts as a new auditor who has never seen the code.
  Re-opens every file. Verifies each fix with a source-code excerpt.

Stage 6 — Validation
  Runs: type check, lint, production build, unit tests, integration tests.
  Reports each check as [PASS], [FAIL], or [SKIP] with explicit reason.

Stage 7 — First-Time User Journey Audit
  Traces every user flow as a new user who has never seen the product.
  Identifies dead ends, false success messages, missing recovery paths.

Stage 8 — Beta Readiness Triage
  Classifies every open finding: Must Fix / Should Fix / Post-Beta / Known Dependency.
  Gives a recommended fix sequence.

Stage 9 — Release Report
  Produces a complete release report.
  Concludes with: Go / Go With Conditions / No-Go and the reasoning.

What This Demonstrates: Skills as Autonomous Workflows

The engineering-audit skill is one of over 200 skills in Bob's skill library. Skills are structured instruction sets — not just prompts — that encode professional workflows so Bob can execute them step-by-step with discipline. The same pattern that makes engineering-audit work applies to sales, legal, HR, finance, marketing, and every other domain. Any expert workflow can become a skill.

The Pattern: How Skills Work
A Bob Skill is a SKILL.md file that encodes:
  • WHO Bob becomes (role definition)
  • WHAT triggers it (when to use)
  • HOW it works (step-by-step workflow with gates and checkpoints)
  • WHAT it produces (structured output format)

The engineering-audit skill encodes the workflow a senior engineer follows
before releasing software — into a reusable, consistently-executed workflow.

Other examples of skills in the library:
  /ibm-pre-001     → Company research + MEDDICC product-fit analysis
  /ibm-des-006     → ROI calculator builder
  /demo-guide-architect → Audience-calibrated demo guide from a raw script
  /agentic-sdlc-lab-guide-builder → Full lab guide from a codebase
  /pitch-master    → Sales narrative from a brief
  /contagious-framework → Viral marketing strategy

Any expert workflow you repeat can be a skill.
A skill runs the same way every time, at the quality of the best practitioner who wrote it.

QisBob — Quantum Computing with IBM Quantum

QisBob is a full Bob mode that acts as a warm, Socratic quantum mentor. It assesses your Python level, picks a learning track (Executive, Developer, or Hardware), and walks you gate-by-gate through Qiskit v2.0+ circuits on real IBM Quantum hardware — quizzing you at every step. No physics PhD required.

Starting Prompt — paste directly into Bob
Switch to QisBob Quantum Mentor mode.

I want to learn quantum computing. I have [no / some / strong] Python experience and [no / basic / advanced] quantum background. Start my quantum loop — assess where I am and build me a personalized learning path. Start the first lesson when you're ready.
How to activate QisBob mode
  1. Open Bob and click the modes button at the bottom-left of the chat input.
  2. Select QisBob Quantum Mentor from the list.
  3. Type "Start my quantum loop" and press Enter.
